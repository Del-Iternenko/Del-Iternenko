### ⚡ About

I build tools that squeeze more out of hardware people already own — GPUs, codecs and game engines included.

- 🎞️ Working on **[ClearFrame](https://github.com/Del-Iternenko/ClearFrame)** — real-time neural upscaling for movies and TV on NVIDIA RTX Tensor Cores
- 🔬 Into video pipelines, inference optimisation and honest benchmarks
- 🛠️ Comfortable going low-level: bytecode patching, D3D11 video processing, WebRTC streaming
- 🎮 Also make games and mods in my spare time

> **ClearFrame** turns soft, over-compressed 480p–720p video into clean 1440p while you watch.
> Step one is done: an open benchmark bench that measures upscalers against the clean original — and shows that driver RTX VSR barely beats bicubic on compressed web video. Next: compact models compiled to TensorRT and a model trained on real streaming artifacts.
